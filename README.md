# Данный проект является дипломным проектом студента колледжа вятского государственного университета группы ИСПк 301-51-00 Бекмансурова Рустама Мхадтисовича;
## Краткое описание системы
### данная дипломная работа предназначена для обработки прайс листов и выгрузки их на маркетплейсы и интернет магазины,
### так же данная система предназначена для формирования прайс листов из готовых провайдеров (парсеров)
### логика добавления парсеров работает по принципу изучения запросов клиентов (изучения потребностей клиентов, если поступает много вопросов по поводу парсинга такой-то площадки, то создается для неё парсер или же клиент сам заказал платную разработку парсера, то данный парсер будет доступен для всех остальных пользователь, как и остальные за подписку), принцип создания остальных интеграций будет базироваться на таком же принципе
## Развертывание системы
### 1) необходимо клонировать репозиторий git clone https://github.com/RustamISPk/price-lists.git или git clone git@github.com:RustamISPk/price-lists.git
### 2) запуск сборки докер образов docker-compose up -d --build
### 3) добавление .env файла
### 4) запуск миграций (пока проект на этапе сборки и миграции не созданы, инструкция появится позже)
